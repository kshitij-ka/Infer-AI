Infer AI
Overview API reference

AI question-answering API

A FastAPI service that authenticates requests with JWT, sends questions to an LLM, and returns the generated answer. Redis handles rate limiting, PostgreSQL handles persistence.

API reference

Four endpoints. All except /health require a bearer token issued by /auth/login.

Login Chat Health Metrics
POST /auth/login No auth required

Authenticates a user and issues a JWT access token.

Request body
{
  "username": "string",
  "password": "string"
}
Response 200
{
  "access_token": "eyJhbGciOiJIUzI1NiJ9...",
  "token_type": "bearer"
}
401: invalid username or password.
POST /chat Bearer token required

Sends a question to the configured LLM and returns the generated answer. Retries once on timeout, then falls back to a secondary model.

Request body
{
  "question": "string"
}
Response 200
{
  "answer": "string",
  "latency_ms": 612,
  "tokens_used": 184,
  "model": "gpt-4o-mini"
}
401: missing or invalid token.
429: rate limit exceeded.
502: LLM provider error after retry.
GET /health No auth required

Checks Redis and database connectivity for load balancer and orchestrator health probes.

Response 200
{
  "status": "ok",
  "checks": {
    "database": "ok",
    "redis": "ok"
  }
}
GET /metrics Admin role required

Returns request latency, LLM token usage, and error rate in Prometheus exposition format.

Response 200 (text/plain)
http_request_duration_seconds{route="/chat"} 0.61
llm_tokens_used_total 184213
chat_requests_total{status="200"} 8420
chat_requests_total{status="502"} 12
